# 智慧乡村综合服务平台 UI/UX 原型

## 项目简介

这是智慧乡村综合服务平台的交互原型，展示了专为农村用户设计的用户界面和交互体验。原型包含完整的用户流程，涵盖村务管理、村民服务、语音交互、应急求助等核心功能。

## 文件结构

```
prototype/
├── index.html          # 主原型文件
├── demo.html           # 设计演示页面
├── styles.css          # 样式文件
├── app.js              # 交互脚本
├── COMPONENT_LIBRARY.md # 组件库文档
├── USER_TESTING_GUIDE.md # 用户测试指南
└── README.md           # 本文件
```

## 特色功能

### 1. 语音优先交互
- 支持22种方言识别
- 语音输入和语音播报
- 语音指令控制

### 2. 适老化设计
- 大字模式切换
- 高对比度模式
- 简化操作流程
- 大触控目标

### 3. 离线可用
- 基础功能离线使用
- 数据自动同步
- 离线表单填写

### 4. 一户一码管理
- 家庭二维码生成
- 家庭关系图谱
- 信息脱敏保护

## 快速开始

### 在线查看
1. 直接打开 `demo.html` 查看设计演示
2. 打开 `index.html` 体验完整原型

### 本地运行
```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server

# 访问 http://localhost:8000
```

### 功能演示

#### 基础导航
- 点击底部导航切换页面
- 使用 Alt+数字键快速导航（Alt+1~4）
- ESC 键返回首页

#### 语音功能
- 点击底部麦克风按钮或按 Alt+V
- 选择支持的方言
- 尝试语音指令："打开村务"、"查询天气"

#### 适老化切换
- 点击"设置"→"大字模式"
- 或在演示页面点击"大字模式"按钮

#### 应急功能
- 点击"应急求助"
- 一键紧急呼叫
- 自动获取位置信息

## 设计系统

### 颜色规范
- 主色：大地绿 (#2E7D32)
- 辅助色：丰收金 (#FFA000)
- 成功：#4CAF50
- 警告：#FF9800
- 错误：#F44336

### 字体规范
- 基础字号：16px
- 大字模式：20px
- 行高：1.6

### 间距系统
- 基础单位：16px
- 触控目标：最小44px
- 大字模式：60px

## 注意事项

1. **语音功能**需要网络连接和浏览器支持
2. **定位功能**需要用户授权
3. **离线功能**使用 localStorage 存储
4. **响应式设计**支持手机、平板、桌面

## 开发建议

### 移动端优化
```html
<!-- viewport 设置 -->
<meta name="viewport" content="width=device-width, initial-scale=1.0, user-scalable=no">

<!-- PWA 支持 -->
<meta name="theme-color" content="#2E7D32">
<link rel="manifest" href="manifest.json">
```

### 性能优化
- 使用 CSS 动画代替 JavaScript
- 图片懒加载
- 压缩资源文件
- 使用 CDN 加速

### 无障碍支持
- 语义化 HTML 标签
- ARIA 标签
- 键盘导航
- 屏幕阅读器支持
