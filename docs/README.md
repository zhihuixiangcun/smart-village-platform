# 智慧乡村综合服务平台 - 项目文档

## 项目概述

智慧乡村综合服务平台是一个面向现代农村治理的数字化解决方案，采用微服务架构设计，为村委会和村民提供全面的数字化服务。平台致力于通过技术创新提升乡村治理效率，改善村民生活质量，推动乡村振兴发展。

### 核心价值

- **村务数字化** - 村委会管理、财务透明、信息公开
- **村民服务** - 在线办事、证件办理、社区互助
- **安全可靠** - 数据加密、权限控制、操作审计
- **多端支持** - Web、移动端、小程序全覆盖

### 应用场景

- 行政村管理 - 完整的村级行政事务数字化
- 社区治理 - 现代化社区管理和服务
- 农业合作社 - 农业生产和经营管理
- 乡镇政府 - 多村统一管理平台

## 技术栈

### 前端技术
- **框架**: Vue.js 3.0+
- **构建工具**: Vite 5.0
- **UI组件**: Element Plus
- **状态管理**: Pinia
- **路由**: Vue Router 4
- **样式**: Tailwind CSS 4.0

### 后端技术
- **运行时**: Node.js 20+
- **框架**: Express.js
- **认证**: JWT + bcryptjs
- **数据库**: MongoDB + Mongoose
- **缓存**: Redis (可选)
- **实时通信**: Socket.IO
- **测试**: Jest
- **日志**: Winston

## 架构概览

### 双服务器架构

项目采用双服务器架构设计，分别处理不同的业务职责：

```
┌─────────────────────────────────────────────────────────────────────┐
│                         前端展示层 (Vue.js)                          │
│                     Port: 3000 (Vite Dev)                          │
└─────────────────────────────────────────────────────────────────────┘
                                    │
                    ┌───────────────┴───────────────┐
                    ▼                               ▼
┌───────────────────────────────────────┐  ┌───────────────────────────────────────┐
│      主API服务器                       │  │      村务服务器                        │
│      Port: 3001                       │  │      Port: 5000                        │
├───────────────────────────────────────┤  ├───────────────────────────────────────┤
│ - 实时监控系统                         │  │ - 核心业务逻辑                         │
│ - 稳定性管理 (限流/熔断)               │  │ - Socket.IO 实时通信                  │
│ - 多语言支持 (i18n)                   │  │ - 文件上传处理                         │
│ - 通知模板                             │  │ - 应急广播系统                         │
│ - API 监控                             │  │ - 村民/公告管理                       │
└───────────────────────────────────────┘  └───────────────────────────────────────┘
                    │                                       │
                    └───────────────┬───────────────────────┘
                                    ▼
                    ┌───────────────────────────────────────┐
                    │         数据存储层                     │
                    ├───────────────────────────────────────┤
                    │ - MongoDB (主数据库)                  │
                    │ - SQLite (开发/测试)                  │
                    │ - Redis (缓存/会话)                   │
                    └───────────────────────────────────────┘
```

## 快速开始

### 环境要求

```json
{
  "node": ">=20.17.0",
  "npm": ">=10.0.0",
  "mongodb": ">=6.0 (可选)"
}
```

### 快速安装

```bash
# 1. 克隆项目
git clone https://github.com/zhihuixiangcun/smart-village-platform.git
cd smart-village-platform

# 2. 安装所有依赖
npm run init

# 3. 环境配置
cp .env.example .env
# 编辑 .env 文件配置数据库连接

# 4. 初始化数据库
npm run init-db

# 5. 启动开发服务
npm run dev && npm run client
```

### 访问地址

- **系统首页**: http://localhost:3000
- **管理后台**: http://localhost:3000/admin
- **监控面板**: http://localhost:3001/monitoring
- **健康检查**: http://localhost:3001/health

## 核心功能模块

### 村委管理模块
- 智能权限管理 - 分级权限体系
- 数字化值班表 - 自动排班、扫码呼叫
- 村情地图功能 - 实时显示村民位置
- 审计追踪系统 - 操作日志全记录

### 村民管理模块
- 一户一码系统 - 每户独立二维码
- 血缘关系管理 - 自动识别家庭成员
- 人脸识别登录 - 支持老年人刷脸查询
- 隐私保护机制 - 数据脱敏显示

### 财务管理模块
- 智能票据识别 - OCR自动识别发票
- 预算控制系统 - 年度预算编制
- 多级审批流程 - 自定义审批链路
- 透明化公示 - 财务收支实时公开

### 村务治理模块
- 在线民主决策 - 支持投票表决
- 多媒体公告发布 - 支持多种格式
- 会议管理系统 - 线上会议管理
- 双向沟通平台 - 村民在线反馈
