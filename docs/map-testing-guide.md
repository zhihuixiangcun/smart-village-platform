### 错误日志及解决方案

#### 错误1: "Error key!"
```
❌ Map JSAPI> Error key!
```
**原因**: Key无效或未配置
**解决**: 已在 `.env` 文件中配置正确的Key

#### 错误2: "AMap is not defined"
```
❌ ReferenceError: AMap is not defined
```
**原因**: API脚本未加载完成
**解决**: 已添加轮询检查机制，等待AMap对象可用

#### 错误3: 容器未找到
```
❌ 地图初始化失败: Error: container not found
```
**原因**: DOM容器不存在
**解决**: 确保在 `onMounted` 之后调用初始化

## 🔧 开发者工具检查

### 1. 检查环境变量
打开浏览器控制台，输入：
```javascript
console.log(import.meta.env.VITE_AMAP_KEY)
```
应该输出: `7da29ab1b7d58cd008724108da7745df`

### 2. 检查API加载
打开控制台，切换到 **Network** 标签：
- 查找 `amap.com` 的请求
- 确保返回状态码 200

### 3. 检查AMap对象
```javascript
console.log(window.AMap)
```
应该输出一个包含地图API的对象

### 4. 检查地图容器
```javascript
document.getElementById('nearby-products-map')
```
应该返回一个 DOM 元素

## 🚨 常见问题

### Q1: 地图显示空白
**A**:
1. 检查控制台是否有错误
2. 确认网络连接正常
3. 刷新页面重试

### Q2: 密钥错误
**A**:
1. 确认 `.env` 文件存在
2. 检查Key是否正确
3. 重启开发服务器

### Q3: 定位失败
**A**:
1. 检查浏览器定位权限
2. 确认HTTPS或localhost环境
3. 尝试手动选择位置

### Q4: 标记不显示
**A**:
1. 确认商品数据存在
2. 检查坐标是否正确
3. 查看控制台错误信息
