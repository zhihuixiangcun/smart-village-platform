# 账号密码登录功能开发说明文档

## 项目概述

**项目名称**: 智慧乡村移动端 - 账号密码登录功能
**优先级**: 高（用户要求优先）
**创建时间**: 2026-01-13
**目标**: 实现安全可靠的账号密码登录系统

## 功能需求

### 核心功能
1. **账号密码登录**
   - 支持用户名/手机号 + 密码登录
   - 密码加密传输（SHA-256）
   - 登录状态持久化（JWT Token）
   - 自动登录功能

2. **密码管理**
   - 忘记密码功能
   - 修改密码功能
   - 密码强度验证
   - 密码可见性切换

3. **登录安全**
   - 错误次数限制（5次锁定30分钟）
   - 验证码防刷
   - 登录日志记录
   - Token自动刷新

## 技术方案

### 前端技术
- **框架**: Vue 3 Composition API
- **表单验证**: 自定义验证器
- **加密**: Web Crypto API (SHA-256)
- **状态管理**: Pinia
- **路由**: Vue Router

### 后端技术
- **认证**: JWT (jsonwebtoken)
- **密码加密**: bcryptjs
- **API**: Express.js
- **数据库**: MongoDB
- **验证**: Joi/express-validator

### 安全措施
1. 密码传输前SHA-256加密
2. 后端bcrypt存储（salt rounds: 10）
3. JWT Token（有效期：7天）
4. HTTPS传输（生产环境）
5. 登录失败次数限制

## API接口设计

### 登录接口
```
POST /api/v1/auth/password/login

Request:
{
  "username": "string",  // 用户名或手机号
  "password": "string"   // SHA-256加密后的密码
}

Response (200):
{
  "success": true,
  "data": {
    "token": "string",
    "refreshToken": "string",
    "user": {
      "id": "string",
      "username": "string",
      "phone": "string",
      "role": "string"
    }
  }
}

Error (401):
{
  "success": false,
  "error": "用户名或密码错误",
  "remainingAttempts": 4
}
```

### 注册接口
```
POST /api/v1/auth/password/register

Request:
{
  "username": "string",
  "password": "string",
  "phone": "string",
  "verificationCode": "string"
}

Response (200):
{
  "success": true,
  "data": {
    "userId": "string"
  }
}
```

### 修改密码接口
```
POST /api/v1/auth/password/change

Request (Authorization: Bearer <token>):
{
  "oldPassword": "string",
  "newPassword": "string"
}

Response (200):
{
  "success": true,
  "message": "密码修改成功"
}
```

### 忘记密码接口
```
POST /api/v1/auth/password/reset

Request:
{
  "phone": "string",
  "verificationCode": "string",
  "newPassword": "string"
}

Response (200):
{
  "success": true,
  "message": "密码重置成功"
}
```

## 安全最佳实践

1. **密码存储**
   - 使用bcrypt加密（salt rounds: 10）
   - 不存储明文密码
   - 定期更新加密算法

2. **Token管理**
   - 使用JWT
   - 设置合理过期时间
   - 实现Token刷新机制
   - 存储在httpOnly Cookie

3. **登录保护**
   - 限制错误次数
   - 使用验证码
   - 记录登录日志
   - 异常登录告警

4. **传输安全**
   - 使用HTTPS
   - 密码传输前加密
   - 防止CSRF攻击
   - 防止XSS攻击
