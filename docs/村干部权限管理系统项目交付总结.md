## 📋 API接口清单

### 村干部管理 API (10个)
```
POST   /api/committee/applications              提交申请
GET    /api/committee/applications              获取申请列表
GET    /api/committee/applications/:id          获取申请详情
PUT    /api/committee/applications/:id/review   审核申请
PUT    /api/committee/applications/:id/cancel   取消申请
GET    /api/committee/roles                     获取角色列表
GET    /api/committee/members                   获取成员列表
PUT    /api/committee/members/:id               更新成员信息
DELETE /api/committee/members/:id               移除成员
GET    /api/committee/statistics                获取统计数据
GET    /api/committee/audit-logs                获取审计日志
```

### 人口管理 API (12个)
```
# 分组管理 (6个)
POST   /api/population/groups                   创建分组
GET    /api/population/groups                   获取分组列表
GET    /api/population/groups/:id               获取分组详情
PUT    /api/population/groups/:id               更新分组
POST   /api/population/groups/:id/members       添加成员
DELETE /api/population/groups/:id/members/:uid  移除成员
DELETE /api/population/groups/:id               删除分组

# 人口变动 (6个)
POST   /api/population/changes                  提交变动
GET    /api/population/changes                  获取变动列表
GET    /api/population/changes/:id              获取变动详情
PUT    /api/population/changes/:id/review       审核变动
GET    /api/population/statistics               获取统计
```

## 🚀 使用指南

### 启动服务

1. **启动主API服务** (端口 3001)
```bash
npm run dev
# 或
npm start
```

2. **启动前端服务** (端口 3006)
```bash
cd client
npm run dev
```

3. **访问应用**
   - 前端: http://localhost:3006
   - API健康检查: http://localhost:3001/health
   - API文档: http://localhost:3001/api/v1/docs

### 认证说明

所有API需要在请求头中携带JWT Token:
```
Authorization: Bearer <your-jwt-token>
```

### 权限代码格式

采用 `模块:操作` 格式:
- `resident:read` - 查看村民信息
- `committee:approve` - 审核村干部申请
- `population:create` - 创建人口变动记录
- `group:update` - 更新村民分组
- `finance:*` - 财务管理所有权限
