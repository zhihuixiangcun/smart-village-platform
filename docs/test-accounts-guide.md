## 登录方式

### 方式一: 手动输入登录

1. 访问前端登录页面
2. 选择"村民"角色
3. 输入用户名和密码(例如: `cengfangguo` / `Ceng@123456`)
4. 勾选"我已阅读并同意用户协议"
5. 点击"登录"按钮

### 方式二: 使用快速测试登录

1. 访问前端登录页面
2. 选择"村民"角色
3. 点击快速测试区域中的"🧑‍🌾 村民"按钮
4. 系统会自动填充岑方国的账号信息并登录

- 创建时间: 2025-01-08

## 故障排除

如果登录失败,请检查:

1. **用户名和密码是否正确** - 注意大小写
2. **角色选择是否正确** - 应选择"村民"
3. **是否勾选了用户协议** - 必须勾选才能登录
4. **后端服务是否运行** - 默认端口3001
5. **前端是否正确配置** - API地址应为 `http://localhost:3001`
