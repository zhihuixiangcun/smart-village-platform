### 3. 更新用户Store

**文件**: `client-mobile/src/store/user.js`

**新增方法**:

#### passwordLogin()
- **功能**: 账号密码登录
- **参数**: `{ account, password, role }`
- **返回**: `{ success, user, message }`
- **特性**: 
  - 密码SHA-256加密传输
  - 自动保存登录状态
  - 支持记住登录

#### codeLogin()
- **功能**: 验证码登录
- **参数**: `{ phone, code, role }`
- **返回**: `{ success, user, message }`

#### faceLogin()
- **功能**: 人脸识别登录
- **参数**: `{ role }`
- **返回**: `{ success, user, message }`

#### wechatLogin()
- **功能**: 微信授权登录
- **参数**: `{ role }`
- **返回**: `{ success, user, message }`

### 4. 安装依赖

**依赖**: crypto-js

**安装命令**:
```bash
npm install crypto-js --legacy-peer-deps
```

**用途**: 密码SHA-256加密
