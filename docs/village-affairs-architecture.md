## 安全架构

```
┌─────────────────────────────────────────────────────────┐
│                    前端安全                              │
├─────────────────────────────────────────────────────────┤
│  • 路由守卫 - requiresAuth                              │
│  • 权限控制 - 基于角色的访问控制                         │
│  • 数据脱敏 - 身份证号、手机号                           │
│  • XSS 防护 - 输入过滤、输出转义                         │
│  • CSRF 防护 - Token 验证                               │
└─────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────┐
│                    后端安全                              │
├─────────────────────────────────────────────────────────┤
│  • JWT 认证                                             │
│  • API 限流 - rate limiting                             │
│  • 数据加密 - AES/RSA                                   │
│  • SQL 注入防护 - 参数化查询                             │
│  • 操作日志 - 审计追踪                                  │
└─────────────────────────────────────────────────────────┘
```
