## 📖 概述

Vibe Kanban 是一个强大的项目管理工具，与智慧乡村平台项目完全集成。它提供了：

- **可视化看板** - 实时跟踪任务进度
- **Git 集成** - 自动监控代码变更
- **PR 监控** - Pull Request 状态追踪
- **文件搜索** - 快速定位项目代码

---

## 🚀 快速开始

### 1. 启动 Vibe Kanban 服务器

```bash
# Windows
set PORT=8080 && npx vibe-kanban

# Linux/Mac
PORT=8080 npx vibe-kanban
```

服务器将在 http://127.0.0.1:8080 启动

### 2. 使用 CLI 工具查看看板

```bash
# 查看看板概览
npm run kanban:overview

# 查看所有任务
npm run kanban:tasks

# 显示帮助
npm run kanban help
```

## 📋 工作流程

```
📥 待办 (TODO) → 🔄 进行中 (IN PROGRESS) → ✅ 审核中 (REVIEW) → 🎉 已完成 (DONE) → ❌ 已关闭 (CLOSED)
```

### 状态说明

| 状态 | 图标 | 说明 | 退出条件 |
|-----|------|-----|---------|
| 待办 | 📥 | 新任务、需求待分析 | 已理解需求，开始规划 |
| 进行中 | 🔄 | 正在开发/实施 | 代码完成，等待自检 |
| 审核中 | ✅ | 代码审查、测试 | 审查通过，测试通过 |
| 已完成 | 🎉 | 已合并/部署 | 功能上线 |
| 已关闭 | ❌ | 取消/延期的任务 | - |

## 🎯 看板文件

项目看板文件位于: [docs/VIBE_KANBAN_PROJECT_BOARD.md](docs/VIBE_KANBAN_PROJECT_BOARD.md)

### 手动更新看板

1. 打开看板文件
2. 找到对应的状态部分
3. 添加/更新任务卡片

#### 任务卡片格式

```markdown
| ID | 任务 | 负责人 | 开始时间 | 进度 |
|----|------|--------|---------|------|
| PROG-001 | 我的任务名称 | - | 2026-01-20 | 50% |
```

## 🎯 最佳实践

### 1. 任务管理

- ✅ 每个任务应有唯一 ID（如: `PROG-001`）
- ✅ 明确的任务描述和验收标准
- ✅ 设置合理的优先级（P1=高, P2=中, P3=低）
- ✅ 及时更新任务进度

### 2. Git 工作流

```bash
# 创建功能分支
git checkout -b feature/my-feature

# 提交代码
git add .
git commit -m "feat: 添加新功能"

# 推送并创建 PR
git push origin feature/my-feature
```

### 3. 代码审查

- 所有代码需经过审查方可合并
- 使用 `✅ 审核中` 状态跟踪审查进度
- 审查通过后移至 `🎉 已完成`
