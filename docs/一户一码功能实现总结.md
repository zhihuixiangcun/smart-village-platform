3. **showQRCode函数** (第1335-1371行):
```javascript
const showQRCode = async () => {
  qrcodeDialogVisible.value = true
  qrCodeLoading.value = true

  try {
    const householdId = userStore.userInfo?.householdId

    if (!householdId) {
      ElMessage.warning('您还未绑定家庭信息，请联系村委会')
      return
    }

    const response = await householdQRApi.generateQR(householdId, { includeImage: true })

    if (response.success) {
      userQRCode.value = response.data.qrImageUrl
      householdInfo.value = response.data.household
      ElMessage.success('二维码生成成功')
    }
  } catch (error) {
    ElMessage.error('生成二维码失败，请稍后重试')
  } finally {
    qrCodeLoading.value = false
  }
}
```

4. **downloadQRCode函数** (第1373-1389行):
```javascript
const downloadQRCode = () => {
  if (!userQRCode.value) {
    ElMessage.warning('请先生成二维码')
    return
  }

  const link = document.createElement('a')
  link.href = userQRCode.value
  link.download = `我的二维码_${userInfo.value.name || '村民'}.png`
  link.click()
  ElMessage.success('二维码已下载')
}
```

5. **shareQRCode函数** (第1391-1410行):
```javascript
const shareQRCode = async () => {
  if (!householdInfo.value) {
    ElMessage.warning('请先生成二维码')
    return
  }

  const householdId = userStore.userInfo?.householdId
  if (householdId) {
    await navigator.clipboard.writeText(householdId)
    ElMessage.success('户码已复制到剪贴板')
  }
}
```

## 🎨 用户体验设计

### 1. 交互流程

```
用户点击"我的二维码"
    ↓
显示对话框（加载状态）
    ↓
检查家庭绑定
    ↓
    ├─ 未绑定 → 显示提示
    │
    └─ 已绑定 → 调用API生成二维码
              ↓
          显示二维码 + 用户信息
              ↓
          操作选项：
          - 下载二维码
          - 分享户码
          - 刷新二维码
```

### 2. 错误处理

- **未绑定家庭**: 友好提示联系村委会
- **API失败**: 自动重试机制，显示错误信息
- **下载失败**: 捕获异常，提示用户
- **分享失败**: 降级处理，显示备用方案

### 3. 性能优化

- 按需加载二维码（点击对话框时才生成）
- 加载状态反馈（Loading动画）
- 图片缓存（避免重复生成）

## 🔧 技术架构

### 数据流程

```
前端 (Vue 3)
    ↓ HTTP请求
后端API (Express)
    ↓ 调用
服务层 (householdQRService)
    ↓ 操作
数据模型 (Household)
    ↓ 生成
二维码 (qrcode库)
    ↓ 返回
前端显示
```

### 安全措施

1. **身份验证**: 需要登录才能生成和查看
2. **权限控制**: 只能查看自己的家庭信息
3. **户码加密**: 唯一编码，防止伪造
4. **数据脱敏**: 敏感信息不公开显示

## 📝 使用文档

### 村民使用指南

1. **如何查看我的二维码？**
   - 登录平台后，点击顶部"我的二维码"按钮
   - 系统自动生成个人专属二维码
   - 可下载保存或分享给他人

2. **如何使用二维码？**
   - 村委会工作人员扫码可查看家庭信息
   - 用于身份验证和办事确认
   - 参与村务活动时签到使用

3. **如何更新家庭信息？**
   - 进入"家庭档案"标签
   - 点击"更新信息"按钮
   - 填写需要修改的内容

### 管理员使用指南

1. **批量生成户码**
   - 进入管理后台
   - 选择"一户一码管理"
   - 点击"批量生成"按钮
   - 选择村庄并确认

2. **查看统计信息**
   - 访问 `/api/v1/household-qr/stats/:villageId`
   - 查看户码生成情况
   - 导出统计报表
