## 🚀 测试步骤

### 方式一：通过村务公开页面访问

1. **登录系统**
   - 访问: `http://localhost:3007`
   - 使用上述任一测试账号登录

2. **进入村务公开页面**
   - 登录后默认进入首页
   - 点击导航菜单中的"村务公开"

3. **查看我的二维码**
   - 在村务公开页面中，找到"我的二维码"卡片

     - 家庭成员数量
     - 二维码图片

### 方式二：直接访问二维码页面

1. **登录系统**
   - 访问: `http://localhost:3007`
   - 使用测试账号登录

2. **直接访问**
   - 在浏览器地址栏输入: `http://localhost:3007/qrcode`
   - 页面将自动加载当前用户的户码信息

## 🔌 API 接口

村务服务器（端口 5000）已添加以下API接口：

### 1. 获取户码信息
```http
POST /api/v1/household-qr/generate/:householdId?includeImage=true
```
- **参数**:
  - `householdId`: 用户ID或户码ID
  - `includeImage`: 是否包含二维码图片
- **返回**: 户码信息和二维码URL

### 2. 公开扫码查看
```http
POST /api/v1/household-qr/public/scan
```
- **Body**: `{ "codeId": "MBAC01H0001A" }`
- **返回**: 公开的户码信息（不含敏感数据）

### 3. 验证户码
```http
POST /api/v1/household-qr/validate
```
- **Body**: `{ "codeId": "MBAC01H0001A" }`
- **返回**: 验证结果

## 🛠️ 技术架构

### 前端
- **组件**: `client/src/views/village/HouseholdQR.vue`
- **路由**: `/qrcode`
- **API**: `client/src/api/householdQR.js`
- **状态管理**: Pinia (userStore)

### 后端
- **服务器**: 村务服务器 (端口 5000)
- **模型**: `src/models/Household.js`
- **路由**: `server/app.js`
- **数据库**: MongoDB

### 数据流程
1. 用户登录 → 获取用户ID
2. 访问 `/qrcode` 页面
3. 组件调用 `loadMyHousehold()`
4. API 请求: `POST /api/v1/household-qr/generate/{userId}`
5. 后端查询 Household 模型
6. 返回户码数据和二维码URL
7. 前端渲染页面
