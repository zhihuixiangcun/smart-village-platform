# 📚 智慧村庄平台用户使用指南

## 🎯 指南概述

本指南旨在帮助不同类型的用户快速上手智慧村庄综合服务平台，包括村民、村委工作人员和采购商等。

## 📋 用户角色

### 👤 普通村民
- 查看村务公告和政策信息
- 在线办理证件和申请服务
- 参与村务投票和民主决策
- 使用邻里互助平台
- 紧急求助和安全保障

### 👨‍💼 村委工作人员
- 管理村民档案和信息
- 发布村务公告和通知
- 处理财务收支和审批
- 组织村务会议和投票
- 系统管理和数据统计

### 🏢 企业/个人采购商
- 注册认证和账户管理
- 浏览和搜索农产品
- 在下单购买和支付
- 供应商对接和合作
- 订单跟踪和售后服务

## 🏠 快速入门

### 1️⃣ 注册账户

#### 村民注册
```bash
# 访问注册页面
http://localhost:3000/register

# 填写基本信息
- 手机号码（必填）
- 身份证号（系统自动加密）
```



#### 个人采购商注册

## 👤 村民用户操作指南

### 📋 查看村务信息

#### 公告浏览
1. **进入公告列表**
   - 首页点击"村务公告"
   - 或导航栏选择"信息公开" → "公告管理"

2. **公告分类**
   - 重要通知：村干部任免、政策传达
   - 村务公开：财务收支、项目进展
   - 生活服务：停水停电、道路维修
   - 文化活动：节日活动、技能培训

3. **公告详情**
   - 查看完整内容
   - 下载附件文件
   - 查看阅读状态
   - 点赞或评论互动

#### 政策查询
1. **搜索政策**
   - 使用关键词搜索：如"补贴"、"农业"、"养老"
   - 按分类浏览：农业政策、民生保障、创业扶持

2. **政策详情**
   - 查看政策全文
   - 了解申请条件
   - 查看办理流程
   - 咨询在线客服

### 🛠️ 在线办事

2. **在线申请**

   - 提交申请

3. **进度跟踪**
   - 查看申请状态

#### 福利申请

2. **提供帮助**

## ❓ 常见问题

### 🔑 登录问题

**Q: 忘记密码怎么办？**
A:
1. 点击"忘记密码"
2. 输入手机号/身份证号
3. 接收验证码
4. 重置登录密码

**Q: 账号无法激活？**
A:
1. 村民用户：联系村委管理员审核
2. 村委用户：联系上级管理员
3. 企业采购商：等待人工审核，一般3-5个工作日

### 📋 操作问题

**Q: 无法上传图片/文件？**
A:
1. 检查文件格式是否支持
2. 检查文件大小是否超过限制
3. 检查网络连接是否正常
4. 尝试刷新页面重新上传

**Q: 无法查看某些信息？**
A:
1. 检查是否有相应的查看权限
2. 联系管理员开通权限
3. 确认信息是否已发布

### 📱 移动端问题

**Q: APP无法安装？**
A:
- 安卓：开启"未知来源"安装权限
- iOS：检查设备系统版本兼容性

**Q：APP功能不完整？**
A：
1. 检查是否为最新版本
2. 清除APP缓存数据
3. 重新下载安装

### 🔒 安全问题

**Q: 个人信息安全如何保障？**
A：
1. 敏感信息加密存储
2 - 完善的权限控制
3 - 操作日志全程记录
4 - 定期安全审计

**Q: 如何保护账户安全？**
A：
1. 定期修改登录密码
2. 开启双因素认证
3. 不在公共设备登录
4. 及时退出登录状态
