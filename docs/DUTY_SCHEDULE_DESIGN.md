# 一、功能概述

## 1.1 功能描述

智能值班表 + 一键呼叫功能是智慧乡村平台的核心村委管理功能，旨在实现：
- **智能化排班**: 自动化值班安排，减少人工调度冲突
- **一键呼叫**: 村民扫码即可联系值班人员，提升应急响应速度
- **全程追踪**: 值班记录、呼叫记录完整可追溯
- **数据统计**: 值班时长、响应时间等数据分析

## 1.2 业务价值

| 用户群体 | 痛点 | 解决方案 | 价值量化 |
|:---------|:-----|:---------|:---------|
| **村干部** | 值班安排冲突、争议多 | 自动化排班、公平轮换 | 排班时间减少80% |
| **村民** | 紧急事找不到人、不知道谁值班 | 扫码一键呼叫、自动联系当前值班人员 | 响应速度提升60% |
| **乡镇监管** | 值班情况难掌握 | 实时监控、数据统计 | 监管效率提升100% |

## 1.3 功能边界

### 包含功能
- 值班日历管理与可视化
- 值班人员智能排班
- 值班二维码生成与分享
- 村民扫码一键呼叫
- 值班记录与呼叫记录
- 值班统计分析

### 不包含功能
- 考勤打卡（由其他模块负责）
- 绩效考核（仅提供数据支持）
- 薪资计算（不涉及）

## 3.2 数据字典

### DutySchedule (值班表)

```yaml
集合名: duty_schedules
字段说明:
  _id: ObjectId - 主键
  villageId: String - 所属村委ID (索引)
  scheduleId: String - 值班安排唯一ID (唯一索引)
  scheduleDate: Date - 值班日期 (索引)
  dutyType: Enum - 值班类型
    - WEEKDAY: 工作日值班
    - WEEKEND: 周末值班
    - HOLIDAY: 节假日值班
    - SPECIAL: 特殊值班
  qrCode: String - 值班二维码内容
  qrCodeUrl: String - 二维码图片URL
  status: Enum - 状态
    - DRAFT: 草稿
    - PUBLISHED: 已发布
    - CANCELLED: 已取消
  notes: String - 备注说明
  createdBy: ObjectId - 创建人ID
  createdAt: Date - 创建时间 (索引)
  updatedAt: Date - 更新时间
```

### DutyOfficer (值班人员)

```yaml
集合名: duty_officers
字段说明:
  _id: ObjectId - 主键
  scheduleId: String - 值班安排ID (索引)
  officerId: String - 值班人员ID (索引)
  officerName: String - 值班人员姓名
  officerPhone: String - 值班人员电话
  dutyType: Enum - 值班类型
    - PRIMARY: 主值班
    - SECONDARY: 副值班
    - BACKUP: 备班
  timeSlot: Object - 值班时段
    start: String - 开始时间 (HH:mm)
    end: String - 结束时间 (HH:mm)
  location: String - 值班地点
  status: Enum - 状态
    - NORMAL: 正常
    - LEAVE: 请假
    - SUBSTITUTE: 替班
  substituteId: String - 替班人员ID (如请假)
  createdAt: Date - 创建时间
```

### DutyLog (呼叫记录)

```yaml
集合名: duty_logs
字段说明:
  _id: ObjectId - 主键
  villageId: String - 所属村委ID (索引)
  logId: String - 呼叫记录唯一ID
  scheduleId: String - 关联值班安排ID (索引)
  officerId: String - 值班人员ID (索引)
  callType: Enum - 呼叫类型
    - QR_CODE: 扫码呼叫
    - PHONE: 电话呼叫
    - ONLINE: 在线留言
    - SYSTEM: 系统派单
  callerInfo: Object - 呼叫人信息
    userId: String - 用户ID (可为空)
    name: String - 姓名
    phone: String - 电话
    address: String - 地址 (可选)
  urgency: Enum - 紧急程度
    - LOW: 一般
    - MEDIUM: 紧急
    - HIGH: 特急
    - EMERGENCY: 特大紧急
  content: String - 呼叫内容
  attachments: [String] - 附件图片URL列表
  responseTime: Date - 首次响应时间
  resolvedTime: Date - 解决时间
  resolution: String - 处理结果
  satisfaction: Number - 满意度评分 (1-5)
  feedback: String - 反馈意见
  status: Enum - 状态
    - PENDING: 待响应
    - RESPONDING: 响应中
    - RESOLVED: 已解决
    - CLOSED: 已关闭
  createdAt: Date - 创建时间 (索引)
  updatedAt: Date - 更新时间
```

## 3.3 索引设计

```javascript
// duty_schedules 集合索引
db.duty_schedules.createIndex({ villageId: 1, scheduleDate: -1 });
db.duty_schedules.createIndex({ scheduleId: 1 }, { unique: true });
db.duty_schedules.createIndex({ status: 1, createdAt: -1 });
db.duty_schedules.createIndex({ villageId: 1, status: 1, scheduleDate: -1 });

// duty_officers 集合索引
db.duty_officers.createIndex({ scheduleId: 1 });
db.duty_officers.createIndex({ officerId: 1, createdAt: -1 });
db.duty_officers.createIndex({ scheduleId: 1, officerId: 1 }, { unique: true });

// duty_logs 集合索引
db.duty_logs.createIndex({ villageId: 1, createdAt: -1 });
db.duty_logs.createIndex({ logId: 1 }, { unique: true });
db.duty_logs.createIndex({ officerId: 1, createdAt: -1 });
db.duty_logs.createIndex({ scheduleId: 1, createdAt: -1 });
db.duty_logs.createIndex({ status: 1, createdAt: -1 });
db.duty_logs.createIndex({ villageId: 1, status: 1, urgency: 1, createdAt: -1 });
```

## 4.3 自动排班算法

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           自动轮班算法                                       │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│  输入:                                                                      │
│  • 值班人员列表                                                              │
│  • 排班时间段 (起止日期)                                                     │
│  • 值班类型 (工作日/周末/节假日)                                              │
│  • 每日值班人数                                                              │
│  • 排除日期 (已安排/特殊日期)                                                │
│                                                                             │
│  算法流程:                                                                  │
│                                                                             │
│  1. 初始化                                                                 │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     • 创建空排班表                                                     │     │
│     • 按日期遍历排班时间段                                            │     │
│     • 标记特殊日期 (节假日/已排班日期)                                 │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  2. 日期分类                                                                │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     • 工作日: 周一至周五                                                │     │
│     • 周末: 周六、周日                                                   │     │
│     • 节假日: 法定节假日                                                 │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  3. 人员分配                                                                │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     FOR EACH date IN schedulePeriod:                                    │     │
│       IF date IS excluded: CONTINUE                                    │     │
│                                                                     │     │
│       determineType = getType(date)  // 工作日/周末/节假日           │     │
│                                                                     │     │
│       // 轮询选择值班人员                                             │     │
│       FOR i IN 1 TO dailyStaffCount:                                │     │
│         officer = getNextOfficer(determineType)                     │     │
│         IF officer NOT available: CONTINUE                          │     │
│                                                                     │     │
│         // 负载均衡: 跳过最近值班人员                                │     │
│         IF officer.dutyRecently(): CONTINUE                         │     │
│                                                                     │     │
│         assignToSchedule(date, officer, i)                          │     │
│         updateOfficerLastDuty(officer)                              │     │
│       END FOR                                                        │     │
│     END FOR                                                          │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  4. 冲突检测                                                                │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     • 检测人员冲突 (一人多班)                                           │     │
│     • 检测时段冲突                                                     │     │
│     • 自动调整或标记冲突                                               │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  5. 公平性校验                                                              │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     • 统计每人值班天数                                                 │     │
│     • 计算方差 (标准差 < 阈值)                                           │     │
│     • 不均衡则重新分配                                                 │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  6. 输出结果                                                                │
│     ┌─────────────────────────────────────────────────────────────────┐     │
│     • 生成值班表                                                       │     │
│     • 标记冲突项                                                       │     │
│     • 生成统计信息                                                     │     │
│     └─────────────────────────────────────────────────────────────────┘     │
│                                                                             │
│  输出: 值班表 + 冲突报告 + 统计信息                                          │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
```

# 七、业务规则

## 7.1 排班规则

```yaml
排班时间规则:
  - 工作日值班: 08:00-18:00
  - 周末值班: 09:00-17:00
  - 节假日值班: 按政府规定时间
  - 特殊值班: 按实际需要设定

人员分配规则:
  - 每日至少1人主值班
  - 可选1人副值班
  - 可选1人备班
  - 同一人不得连续值班超过3天
  - 一周内值班天数不超过4天

优先级规则:
  - 备班 > 副值班 > 主值班 (当有人请假时)
  - 值班次数少者优先
  - 距离上次值班时间久者优先

冲突处理:
  - 一人多班: 自动选择最近时段
  - 时段重叠: 合并或标记冲突
  - 人员不足: 提前3天预警
```

## 7.2 呼叫规则

```yaml
呼叫限流:
  - 同一用户10分钟内最多呼叫3次
  - 紧急呼叫不受限制
  - 恶意呼叫自动拉黑

响应时效:
  - 一般: 24小时内响应
  - 紧急: 4小时内响应
  - 特急: 1小时内响应
  - 特大紧急: 立即响应

升级机制:
  - 超时未响应: 自动通知副值班
  - 副值班无响应: 通知村主任
  - 村主任无响应: 通知乡镇

满意度评价:
  - 解决后24小时内可评价
  - 评价内容存档
  - 差评自动触发回访
```

```yaml
值班通知:

    - 值班时段

  通知对象: 副值班/村主任
```
