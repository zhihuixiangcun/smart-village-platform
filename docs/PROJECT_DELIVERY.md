## 🎯 一、项目背景与目标

### 1.1 项目背景

智慧乡村综合服务平台是为响应国家乡村振兴战略，结合乡村治理现代化需求而开发的综合性数字化平台。平台旨在解决乡村治理中的信息不对称、服务效率低、村民参与度不高等问题。

### 1.2 核心目标

- ✅ **村民管理数字化**: 建立完善的村民档案系统，实现"一户一码"管理
- ✅ **村务治理透明化**: 财务公开、项目公示，增强村民信任
- ✅ **政务服务便捷化**: 线上办事、减少跑动，提升服务效率
- ✅ **应急响应快速化**: 一键求助、快速调度，保障村民安全
- ✅ **乡村服务智能化**: 语音交互、适老化设计，降低使用门槛

### 1.3 目标用户

| 用户类型 | 占比 | 主要需求 |
|----------|------|----------|
| 普通村民 | 75% | 信息查询、在线办事、紧急求助 |
| 村委会干部 | 15% | 村务管理、数据分析、任务调度 |
| 乡镇政府 | 8% | 数据监管、统计报表、政策下达 |
| 企业/合作社 | 2% | 资源对接、服务发布、电商合作 |

### 7.2 快速部署

#### 方式一: Docker部署 (推荐)

```bash
# 1. 克隆项目
git clone https://github.com/your-org/smart-village-platform.git
cd smart-village-platform

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件，填写必要配置

# 3. 启动服务
docker-compose up -d

# 4. 初始化数据库
docker-compose exec api npm run init-db

# 5. 访问应用
# 前端: http://localhost:3000
# 后端: http://localhost:3001
```

#### 方式二: 手动部署

```bash
# 1. 安装依赖
npm install

# 2. 配置环境变量
cp .env.example .env
# 编辑 .env 文件

# 3. 初始化数据库
npm run init-db

# 4. 构建前端
cd client && npm run build

# 5. 启动后端服务
npm run prod

# 6. 配置Nginx反向代理
sudo cp deployment/nginx.conf /etc/nginx/sites-available/smart-village
sudo ln -s /etc/nginx/sites-available/smart-village /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
```

### 7.3 生产环境配置

#### Nginx配置示例
```nginx
upstream api_backend {
    server localhost:3001;
    keepalive 64;
}

upstream village_backend {
    server localhost:5000;
    keepalive 64;
}

server {
    listen 443 ssl http2;
    server_name village.example.com;

    ssl_certificate /path/to/certificate.pem;
    ssl_certificate_key /path/to/private-key.pem;

    # 前端静态文件
    location / {
        root /var/www/smart-village/client/dist;
        try_files $uri $uri/ /index.html;
    }

    # API代理
    location /api/ {
        proxy_pass http://api_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
    }

    # Socket.IO代理
    location /socket.io/ {
        proxy_pass http://village_backend;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
    }
}
```
