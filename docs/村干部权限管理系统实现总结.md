# 村干部权限管理系统 - 实现总结

## 📋 项目概述

本文档总结了为智慧乡村平台实现的完整村干部权限管理系统，包含数据库模型、权限配置、工具类和中间件。

## 🎯 核心功能

### 1. 五级村干部角色体系

| 角色 | 代码 | 权限等级 | 主要职责 |
|------|------|----------|----------|
| 村支书 | `secretary` | 5 | 最高权限，负责审核审批 |
| 村主任 | `village_head` | 4 | 村务管理、财务审批 |
| 会计 | `accountant` | 3 | 财务数据管理 |
| 人口主任 | `population_admin` | 3 | 村民信息、人口管理 |
| 治保主任 | `security_director` | 3 | 安全管理、应急响应 |

### 2. 权限矩阵 (RBAC模型)

- **数据访问权限**: 村民数据、财务数据、村务数据、安全日志
- **操作权限**: 增删改查、审核、审批、导出
- **功能模块权限**: 公告发布、任务调度、财务管理、人口管理、安全管理

## 🔧 使用示例

### 1. 权限验证中间件

```javascript
const { checkPermission } = require('../middleware/newPermissionMiddleware');

// 单个权限
router.delete('/api/residents/:id',
  checkPermission('resident:delete', { checkApproval: true }),
  deleteResidentHandler
);

// 多个权限（满足其一即可）
router.post('/api/finance/transactions',
  checkPermission(['finance:create', 'finance:approve'], { checkApproval: true }),
  createTransactionHandler
);

// 带数据范围检查
router.get('/api/residents/:userId',
  checkPermission('resident:read', { checkDataScope: true }),
  getResidentHandler
);
```

### 2. 角色验证中间件

```javascript
const { requireSecretary, requirePopulationAdmin } = require('../middleware/newPermissionMiddleware');

// 只有村支书可以访问
router.post('/api/committee/applications/:id/review',
  requireSecretary,
  reviewApplicationHandler
);

// 人口主任或村支书可以访问
router.post('/api/population/changes',
  requirePopulationAdmin,
  createPopulationChangeHandler
);
```

### 3. 审计日志中间件

```javascript
const { auditLog } = require('../middleware/newPermissionMiddleware');

router.delete('/api/residents/:id',
  checkPermission('resident:delete'),
  auditLog('删除村民', true),  // 敏感操作
  deleteResidentHandler
);
```

### 4. 数据脱敏

```javascript
const PermissionHelper = require('../utils/permissionHelper');

// 自动过滤敏感字段
```

### 5. 权限检查

```javascript
const PermissionHelper = require('../utils/permissionHelper');

// 检查权限
if (PermissionHelper.hasPermission(req.userRole, 'resident:delete')) {
  // 执行操作
}

// 检查是否需要审批
const approvalCheck = PermissionHelper.checkApprovalNeeded(
  req.userRole,
  'finance:approve',
  { amount: 60000 }
);

if (approvalCheck.required) {
  // 需要村主任审批
}
```

## 🔐 安全特性

1. **敏感数据加密**: 身份证号使用AES-256加密存储
2. **数据脱敏**: 自动脱敏手机号、身份证号等敏感字段
3. **操作审计**: 所有操作记录审计日志
4. **权限验证**: 基于RBAC的细粒度权限控制
5. **审批流程**: 敏感操作需要上级审批
6. **二次验证**: 支持人脸识别、短信验证码二次验证
7. **每日限额**: 支持设置每日操作限额
8. **数据范围**: 支持all/department/self三级数据范围控制
