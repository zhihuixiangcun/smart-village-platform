# 移动端5角色功能测试验证指南

## 概述

本文档提供完整的测试验证流程，确保所有5个角色的移动端功能页面正常工作。

---

## 测试前准备

### 1. 确认开发服务器运行

```bash
cd client
npm run dev
```

服务器应在 `http://localhost:3000` 运行。

### 2. 确认后端服务器运行

```bash
# 主API服务器 (端口 3001)
npm run dev

# 村庄服务服务器 (端口 5000) - 如果需要
cd server && npm run dev
```

### 3. 测试账号准备

确保每个角色都有测试账号：

## 快速验证脚本

使用以下命令快速验证页面可访问性：

```javascript
// 在浏览器控制台执行
const routes = [
  '/mobile/resident/profile',
  '/mobile/resident/feedback',
  '/mobile/village-cadre/residents',
  '/mobile/purchaser/suppliers',
  '/mobile/township/audit',
  '/mobile/admin/users'
];

routes.forEach(route => {
  fetch(route)
    .then(() => console.log('✓', route, '可访问'))
    .catch(() => console.log('✗', route, '无法访问'));
});
```
