# 智慧乡村平台 - 多角色登录系统

## 概述

智慧乡村平台支持多种角色登录，不同角色拥有不同的权限和功能模块，提供个性化的登录体验和功能访问。

## 角色类型

### 1. 村民 (Resident)

**权限范围**: 个人事务、信息查询、邻里互助

**功能模块**:

- ✅ 办事大厅（证件办理、福利申请）
- ✅ 信息查询（村务公告、政策查询）
- ✅ 邻里互助（发布需求、互相帮助）
- ✅ 个人中心（个人信息、设置管理）
- ✅ 语音助手（方言语音交互）

**登录入口**: http://localhost:3008/auth/login → 选择"村民"角色

### 2. 村干部 (Village Official)

**权限范围**: 村务管理、资料收集、值班安排

**功能模块**:

- ✅ 村务公开（发布公告、政策宣传）
- ✅ 资料收集（村民资料、档案管理）
- ✅ 值班管理（值班安排、交接记录）
- ✅ 人口管理（村民信息、户籍管理）
- ✅ 任务调度（任务分配、进度跟踪）

**登录入口**: http://localhost:3008/auth/login → 选择"村干部"角色

**包含职务**:

- 村书记
- 村主任
- 副主任
- 会计
- 村委成员

### 3. 乡镇干部 (Township Official)

**权限范围**: 多村管理、政策传达、监督指导

**功能模块**:

- ✅ 多村管理（多个村庄的统一管理）
- ✅ 政策传达（政策发布和通知）
- ✅ 监督指导（工作监督和指导）
- ✅ 数据统计（全镇数据汇总分析）
- ✅ 报表查看（各类报表和统计分析）

**登录入口**: http://localhost:3008/auth/login → 选择"乡镇干部"角色

### 4. 采购商 (Purchaser)

**权限范围**: 农产品采购、订单管理、供应商对接

**功能模块**:

- ✅ 产品浏览（浏览各村农产品信息）
- ✅ 订单管理（采购订单创建和管理）
- ✅ 供应商对接（与各村供应商联系）
- ✅ 价格查询（实时价格查询和对比）
- ✅ 合同管理（采购合同管理）
- ✅ 物流跟踪（订单物流状态查询）

**登录入口**: http://localhost:3008/auth/login → 选择"采购商"角色

### 5. 管理员 (Admin)

**权限范围**: 系统配置、用户管理、权限控制

**功能模块**:

- ✅ 系统配置（参数设置、系统监控）
- ✅ 用户管理（账号管理、角色分配）
- ✅ 权限控制（权限配置、访问控制）
- ✅ 数据管理（数据备份、数据恢复）
- ✅ 系统监控（性能监控、日志管理）
- ✅ 安全管理（安全策略、审计日志）

**登录入口**: http://localhost:3008/auth/login → 选择"管理员"角色

## 登录流程

### 步骤1: 访问登录页面

访问 http://localhost:3008/auth/login

### 步骤2: 选择角色

系统显示4个角色卡片，用户根据身份选择对应角色：

- 村民（绿色图标）
- 村委会成员（黄色图标）
- 村领导（紫色图标）
- 系统管理员（粉色图标）

### 步骤3: 输入登录信息

- 手机号：11位手机号码
- 密码：首次登录为手机号后6位
- 村庄选择：村委会成员和村领导需选择所属村庄

### 步骤4: 登录验证

系统验证：

1. 手机号格式（11位数字）
2. 密码长度（至少6位）
3. 角色权限匹配
4. 村庄归属关系（如需要）

### 步骤5: 登录成功

- 记住登录（可选）：保存手机号和角色信息
- 自动跳转到对应角色的首页
- 保存登录状态到本地存储

## 登录特性

### 1. 角色记忆

- 勾选"记住登录"后，下次登录自动选择上次使用的角色
- 保存手机号和角色信息到本地存储

### 2. 多种登录方式

- **账号密码登录**: 使用手机号和密码
- **人脸识别登录**: 快速便捷的身份验证
- **短信验证码登录**: 忘记密码时使用

### 3. 忘记密码

1. 点击"忘记密码"
2. 输入注册手机号
3. 获取并输入验证码
4. 设置新密码

### 4. 用户注册

- 仅村民角色支持自主注册
- 需要填写：姓名、手机号、身份证号、密码
- 其他角色由系统管理员分配

### 5. 安全特性

- ✅ 密码加密存储（bcrypt）
- ✅ 安全加密传输（HTTPS）
- ✅ 登录状态验证（JWT Token）
- ✅ 权限控制（RBAC）
- ✅ 操作日志记录

## 开发说明

### 文件位置

- 登录页面: `client/src/views/auth/RoleLogin.vue`
- 用户状态: `client/src/stores/user.js`
- 路由配置: `client/src/router/index.js`

### API接口

```javascript
// 登录接口
POST /api/v1/auth/login
{
  phone: "13800138000",
  password: "123456",
  role: "resident",
  villageId: "1"
}

// 支持的角色类型:
// - resident: 村民
// - village_official: 村干部
// - township_official: 乡镇干部
// - purchaser: 采购商
// - admin: 管理员

// 注册接口（村民和采购商可自主注册）
POST /api/v1/auth/register
{
  name: "张三",
  phone: "13800138000",
  idCard: "110101199001011234",
  password: "123456",
  villageId: "1",
  role: "resident"  // 或 "purchaser"
}

// 重置密码
POST /api/v1/auth/reset-password
{
  phone: "13800138000",
  verifyCode: "123456",
  newPassword: "654321"
}

// 人脸登录
POST /api/v1/auth/face-login
{
  faceData: "base64_encoded_face_features",
  role: "resident"
}
```

### 角色权限配置

权限配置在用户模型的 `permissions` 字段中，格式：

```javascript
{
  module: "module_name",
  actions: ["create", "read", "update", "delete", "approve", "export"]
}
```

## 原有账号兼容性

### 村民账号迁移

系统完全兼容原有的村民账号，原有村民账号无需任何修改即可正常使用新角色系统。

**原有村民账号包含的角色**:

- `resident` - 普通村民（保持不变）

**登录方式**:

1. 访问 http://localhost:3008/auth/login
2. 直接选择"村民"角色
3. 输入原有手机号和密码
4. 系统自动识别为村民角色

**数据完整性**:

- ✅ 保留所有原有村民数据
- ✅ 保留村民的个人信息
- ✅ 保留村民的历史记录
- ✅ 保留村民的设置偏好

### 角色升级

如果原有村民需要升级为村干部，需要：

1. 由管理员手动在后台修改角色
2. 重新登录时选择"村干部"角色
3. 系统会显示相应的管理功能模块

### 多角色支持

一个用户可以同时拥有多个角色（例如：既是村民又是采购商），登录时可以选择使用哪个角色登录。

**实现方式**:

- 用户账号的 `role` 字段可以是一个数组
- 登录时系统会显示用户拥有的所有角色
- 用户可以选择使用哪个角色登录

## 常见问题

### Q: 忘记登录密码怎么办？

A: 点击"忘记密码"，通过手机验证码重置密码。

### Q: 如何修改自己的角色？

A: 角色由系统管理员分配，普通用户不能自行修改。

### Q: 村民可以注册吗？

A: 可以，村民角色和采购商角色支持自主注册功能。

### Q: 原有村民账号还能用吗？

A: 可以，原有村民账号完全兼容，无需任何修改。

### Q: 如何成为村干部？

A: 需要由乡镇或上级任命，并由管理员在系统中分配角色。

### Q: 采购商如何入驻？

A: 采购商可以自主注册账号，由管理员审核后开通采购权限。

### Q: 乡镇干部可以管理哪些村庄？

A: 乡镇干部可以管理所属乡镇下的所有村庄。

### Q: 人脸登录如何设置？

A: 登录后在个人中心进行人脸绑定，绑定后可使用人脸登录。

### Q: 同时可以在多个设备登录吗？

A: 可以，系统支持多设备登录，每个设备都会记录登录信息。

### Q: 登录失败怎么办？

A: 请检查手机号和密码是否正确，或联系系统管理员重置密码。
