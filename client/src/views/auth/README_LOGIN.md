# 登录页面优化文档

## 概述

本项目优化了智慧乡村平台的登录页面，提供了多种登录方式和全新的用户体验，显著提升了登录的便捷性和安全性。

## 新增页面

### 增强版统一登录页 (`EnhancedLogin.vue`)

**路由**: `/auth/login-v3`

**特点**:
- 全新的现代化UI设计
- 左右分栏布局：品牌展示 + 登录表单
- 双模式登录：账号登录 / 验证码登录
- 快速登录方式：人脸识别 / 微信登录 / 角色登录
- 密码显示/隐藏切换
- 记住登录状态
- 忘记密码功能
- 实时表单验证
- 完全响应式设计

**核心功能**:
1. **账号登录**: 手机号 + 密码
2. **验证码登录**: 手机号 + 短信验证码
3. **人脸识别**: 快速生物识别登录
4. **微信登录**: 第三方快捷登录
5. **角色登录**: 针对不同角色的专属登录页

## 登录流程

### 账号登录流程

```
1. 输入手机号（11位）
   ↓ 验证格式
2. 输入密码
   ↓ 实时验证
3. 可选：勾选"记住登录"
   ↓
4. 点击"立即登录"
   ↓ API调用
5. 登录成功
   ↓ 角色判断
6. 跳转到对应首页
```

### 验证码登录流程

```
1. 输入手机号
   ↓ 验证格式
2. 点击"获取验证码"
   ↓ 发送短信
3. 输入验证码（6位）
   ↓ 倒计时60秒
4. 点击"立即登录"
   ↓ API调用
5. 登录成功
   ↓ 跳转到首页
```

### 忘记密码流程

```
1. 点击"忘记密码？"
   ↓ 打开弹窗
2. 输入手机号
   ↓
3. 获取验证码
   ↓
4. 输入验证码和新密码
   ↓
5. 点击"确认重置"
   ↓ API调用
6. 密码重置成功
   ↓ 返回登录
```

## 核心特性

### 表单验证

#### 账号登录验证
- **手机号**: 11位数字，必须以1开头，第二位3-9
- **密码**: 6-20位字符

#### 验证码登录验证
- **手机号**: 11位数字，必须以1开头，第二位3-9
- **验证码**: 6位数字

#### 重置密码验证
- **手机号**: 11位数字，必须以1开头，第二位3-9
- **验证码**: 6位数字
- **新密码**: 8-20位字符
- **确认密码**: 必须与新密码一致

### 验证码功能

- **发送前验证**: 手机号格式正确才可发送
- **倒计时限制**: 60秒后才能重新发送
- **独立倒计时**: 登录和重置密码使用独立倒计时

### 密码显示

- 点击眼睛图标切换显示/隐藏
- 图标状态动态变化（View / Hide）
- 提升用户体验

### 记住登录

- 勾选后记住手机号
- 下次自动填充
- 存储在localStorage

### 角色跳转

根据用户角色自动跳转到对应首页：

| 角色 | 跳转路径 |
|------|----------|
| 村民 | /village/affairs |
| 村干部 | /village/dashboard |
| 采购商 | /services/hall |
| 管理员 | /pc/dashboard |

## API集成

### 登录接口

```javascript
// 密码登录
import villageUserApi from '@/api/villageUser';

const handlePasswordLogin = async () => {
  const response = await villageUserApi.login(passwordForm);
  // 处理登录成功
};

// 短信验证码登录
const handleSmsLogin = async () => {
  const response = await villageUserApi.smsLogin(smsForm);
  // 处理登录成功
};

// 重置密码
const handleResetPassword = async () => {
  await villageUserApi.changePassword(resetForm);
  // 处理重置成功
};
```

### API端点

- **密码登录**: `POST /api/village-users/login`
- **短信登录**: `POST /api/village-users/sms-login`
- **重置密码**: `PUT /api/village-users/password`
