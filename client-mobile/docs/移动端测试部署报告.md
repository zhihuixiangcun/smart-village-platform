### 6. 代码质量检查 ⚠️

**测试时间**: 2026-01-13
**命令**: `npm run lint`
**测试结果**: 警告

**问题统计**:
- ❌ 错误: 63个
- ⚠️ 警告: 87个

**主要问题类型**:

1. **Vue文件解析错误** (40+个错误)
   - 原因: ESLint配置缺少Vue解析器插件
   - 影响: 无法正确检查.vue文件
   - 优先级: 高

2. **未使用的变量** (多个)
   - `main.js`: `options` 参数未使用
   - `network.js`: `data` 变量赋值但未使用
   - `user.js`: `oldPassword`, `newPassword`, `code` 参数未使用

3. **Console语句** (87个警告)
   - 位置: `store/chat.js`, `store/elderly.js`, `store/network.js`, `store/user.js`
   - 建议: 生产环境应移除或使用日志库

4. **Promise错误处理**
   - `helpers.js`: 应抛出Error对象
   - `request.js`: 应抛出Error对象

5. **未定义变量**
   - `helpers.js`: `uni` 未定义（可能需要全局声明）

**修复建议**:

1. 安装并配置Vue插件：
```bash
npm install --save-dev eslint-plugin-vue
```

2. 更新`.eslintrc.js`配置：
```javascript
module.exports = {
  extends: [
    'eslint:recommended',
    'plugin:vue/vue3-recommended'
  ],
  // ...
}
```

3. 移除或注释console语句
4. 修复未使用的变量
5. 标准化Promise错误处理

**结论**: 代码存在质量问题，但不影响构建和运行。建议优先修复Vue解析器配置。

### 7. 测试套件测试 ⚠️

**测试时间**: 2026-01-13
**命令**: `npm test`
**测试结果**: 失败

**错误信息**:
```
Error: Failed to load url G:/claude code/tests/setup.js
(resolved id: G:/claude code/tests/setup.js). Does the file exist?
```

**问题分析**:
- 测试配置`vitest.config.js`中引用了`./tests/setup.js`
- 路径解析出现问题
- 实际文件存在于`client-mobile/tests/setup.js`

**修复方案**:
```javascript
// vitest.config.js
setupFiles: ['./tests/setup.js']
// 改为绝对路径或相对路径
setupFiles: [resolve(__dirname, 'tests/setup.js')]
```

**结论**: 测试框架配置问题，需要修复路径引用。

### 部署步骤

1. **构建生产版本**
   ```bash
   cd client-mobile
   npm run build
   ```

2. **验证构建产物**
   ```bash
   ls -la dist/
   ```

3. **部署到服务器**
   ```bash
   # 将dist目录上传到服务器
   scp -r dist/* user@server:/var/www/mobile/
   ```

4. **配置Nginx**
   ```nginx
   server {
       listen 80;
       server_name mobile.smartvillage.com;
       root /var/www/mobile;
       index index.html;

       location / {
           try_files $uri $uri/ /index.html;
       }

       location /api {
           proxy_pass http://localhost:3001;
       }
   }
   ```

5. **验证部署**
   - 访问 http://mobile.smartvillage.com
   - 检查PWA安装
   - 测试关键功能
