# 智慧乡村登录页面使用指南

## 快速开始

### 1. 使用增强版登录页面

将路由指向新的增强版登录页面：

```javascript
// router/index.js
{
  path: '/auth/login',
  name: 'Login',
  component: () => import('@/pages/auth/login-enhanced.vue')
}
```

### 2. 适老化模式设置

#### 开启适老化模式

用户可以通过以下方式开启适老化模式：

1. 在登录页面底部点击"适老化模式"按钮
2. 或者在设置页面中开启

#### 适老化模式功能

- **大字体**：所有文字放大，易于阅读
- **大按钮**：可点击区域增大，更容易操作
- **语音播报**：自动播报操作提示
- **高对比度**：可选高对比度模式

### 3. 语音功能

#### 语音播报

启用语音播报后，系统会自动播报以下内容：

- 页面加载欢迎语
- 选择角色时的提示
- 验证码获取成功
- 登录成功/失败
- 错误提示信息

#### 语音输入（开发中）

在手机号输入框右侧有一个麦克风图标，点击后可以通过语音输入手机号。

### 4. 高对比度模式

高对比度模式适合视力不佳的用户，特点：

- 黑色背景，白色文字
- 高对比度的边框和按钮
- 醒目的错误提示

## 登录流程

### 标准登录流程

1. 选择用户身份（村民、村干部、乡镇官员、管理员）
2. 输入手机号（11位数字）
3. 点击"获取验证码"按钮
4. 验证码自动填充到输入框
5. 勾选用户协议
6. 点击"登录"按钮
7. 登录成功后跳转到相应页面

### 适老化模式登录流程

1. 系统播报欢迎语
2. 听到语音提示后选择角色
3. 输入手机号（支持语音输入）
4. 获取验证码，系统播报验证码
5. 勾选协议（按钮更大）
6. 点击登录（按钮更大）
7. 听到"登录成功"播报后自动跳转

## 功能特性

### 1. 验证码自动填充

- 点击"获取验证码"后，验证码自动填充到输入框
- 系统播报验证码内容（如果语音开启）
- 60秒倒计时，期间禁用重新获取

### 2. 实时验证

- 手机号输入时实时验证格式
- 错误提示显示在输入框下方
- 错误状态输入框变红

### 3. 加载状态

- 登录按钮显示加载动画
- 防止重复提交
- 登录成功后显示成功状态

### 4. 快捷登录

支持多种快捷登录方式：

- 微信登录
- 人脸识别（开发中）
- 密码登录

### 5. 错误处理

- 使用 Toast 提示替代 alert
- 错误信息清晰明确
- 支持语音播报错误信息

## 适配说明

### 屏幕尺寸

- **大屏手机（>480px）**：标准布局
- **中屏手机（375-480px）**：紧凑布局
- **小屏手机（<375px）**：极简布局

### 特殊屏幕

- **刘海屏**：自动处理顶部安全区域
- **动态岛**：自动处理顶部安全区域
- **横屏模式**：优化横屏显示

### 浏览器

- 推荐使用 Chrome、Safari、Edge 最新版
- 语音功能需要浏览器支持 Web Speech API
- 震动功能需要设备支持 Vibration API

## 键盘快捷键

- **Tab**：在可交互元素间切换焦点
- **Enter**：激活当前焦点元素
- **Space**：激活按钮或复选框
- **Esc**：关闭弹出层

## 无障碍特性

### 屏幕阅读器

- 所有元素都有合适的 ARIA 标签
- 错误提示使用 role="alert"
- 按钮状态使用 aria-pressed

### 键盘导航

- 完全支持键盘操作
- 清晰的焦点样式
- 合理的 Tab 顺序

### 色彩对比度

- 文字和背景对比度 >= 4.5:1
- 大文字对比度 >= 3:1
- 符合 WCAG 2.1 Level AA 标准

## 常见问题

### Q1: 验证码没有自动填充？

A: 请检查：
- 是否输入了正确的手机号
- 是否点击了"获取验证码"按钮
- 浏览器是否允许自动填充

### Q2: 语音播报不工作？

A: 请检查：
- 语音功能是否开启
- 浏览器是否支持 Web Speech API
- 设备音量是否开启

### Q3: 震动没有反馈？

A: 请检查：
- 震动反馈是否开启
- 设备是否支持震动
- 浏览器是否允许震动

### Q4: 高对比度模式如何开启？

A:
1. 打开设置页面
2. 找到"显示设置"
3. 开启"高对比度模式"

### Q5: 如何切换回标准模式？

A:
1. 在登录页面底部点击"标准模式"按钮
2. 或者在设置页面中关闭适老化模式
