# 聊天功能增强测试指南

## 功能概述

本次更新为智慧乡村移动端聊天功能增加了以下仿微信功能：

1. **相册功能** - 浏览选择照片并发送
2. **拍照功能** - 调用摄像头拍照并发送
3. **视频通话** - WebRTC实时音视频通话
4. **位置共享** - 发送和查看地图位置
5. **红包功能** - 发送红包和领取红包
6. **礼物功能** - 发送虚拟礼物和动画效果
7. **转账功能** - 余额转账和记录查询
8. **卡券功能** - 发送优惠券和兑换券

## 快速开始

### 启动开发服务器

```bash
cd client-mobile
npm run dev
```

服务器将在 http://localhost:3001 启动（端口可能自动调整）

### 访问聊天页面

1. 打开浏览器访问 http://localhost:3001
2. 导航到聊天详情页面: http://localhost:3001/chat/detail/conv_001
3. 点击输入框左侧的 ➕ 按钮打开更多功能面板

## 功能测试

### 1. 相册功能

**操作步骤**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 🖼️ 相册按钮
3. 在文件选择对话框中选择一张或多张图片
4. 图片会自动发送到聊天窗口

**预期结果**:
- 图片消息显示在聊天窗口
- 支持同时发送多张图片
- 显示发送成功的 Toast 提示

**注意事项**:
- 目前使用本地图片，未实现服务器上传
- 图片大小可能影响显示性能

### 2. 拍照功能

**操作步骤**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 📸 拍照按钮
3. 在浏览器相机界面拍照
4. 照片会自动发送到聊天窗口

**预期结果**:
- 照片显示在聊天窗口
- 显示发送成功的 Toast 提示

**注意事项**:
- 需要 HTTPS 或 localhost 环境才能访问摄像头
- 部分浏览器可能需要用户授权

### 3. 视频通话

**操作步骤**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 📹 视频通话按钮
3. 在视频通话界面测试:
   - 点击静音按钮 (🎤) 切换麦克风
   - 点击视频按钮 (📹) 切换摄像头
   - 点击翻转按钮 (🔄) 切换前后摄像头
   - 点击挂断按钮 (📞) 结束通话

**预期结果**:
- 显示本地摄像头画面（画中画）
- 显示远程摄像头画面（主画面）
- 显示通话时长
- 各控制按钮正常工作

**注意事项**:
- 目前为模拟模式，未实现真正的视频连接
- 需要信令服务器支持完整的 WebRTC 功能
- WebRTC 需要 TURN/STUN 服务器支持 NAT 穿透

### 4. 位置共享

**发送位置**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 📍 位置按钮
3. 浏览器会请求定位权限
4. 位置消息发送到聊天窗口

**查看位置**:
1. 点击聊天窗口中的位置消息
2. 会打开腾讯地图显示位置

**预期结果**:
- 发送位置消息包含坐标和地址信息
- 点击后打开地图显示位置
- 显示发送成功的 Toast 提示

**注意事项**:
- 需要 HTTPS 环境才能获取地理位置
- 使用腾讯地图 API
- 部分设备可能需要用户授权定位

### 5. 红包功能

**发送红包**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 🧧 红包按钮
3. 选择红包类型:
   - 拼手气红包 - 随机金额
   - 普通红包 - 固定金额
4. 输入红包金额和数量
5. 输入祝福语（可选）
6. 点击"塞钱进红包"按钮

**领取红包**:
1. 点击聊天窗口中的红包消息
2. 在红包界面点击"开"按钮
3. 显示领取金额

**预期结果**:
- 发送成功显示红包消息
- 领取红包显示随机金额
- 红包状态正确更新

**注意事项**:
- 目前为前端模拟，未连接真实支付系统
- 需要后端支持红包资金流转
- 需要数据库存储红包记录

### 6. 礼物功能

**操作步骤**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 🎁 礼物按钮
3. 在礼物列表中选择一个礼物
4. 调整发送数量（1-99）
5. 点击"发送"按钮

**预期结果**:
- 显示礼物飞行动画
- 礼物消息显示在聊天窗口
- 显示金币扣减提示

**注意事项**:
- 目前为模拟金币系统
- 需要后端支持礼物金币扣减
- 需要数据库存储礼物记录

### 7. 转账功能

**操作步骤**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 💰 转账按钮
3. 输入转账金额
4. 输入转账说明（可选）
5. 点击"确认转账"按钮
6. 输入6位支付密码（模拟密码: 123456）

**预期结果**:
- 转账成功显示转账消息
- 余额自动扣减
- 显示转账成功的 Toast 提示

**注意事项**:
- 目前为模拟密码系统
- 需要后端支持资金安全
- 需要数据库存储转账记录

### 8. 卡券功能

**发送卡券**:
1. 点击 ➕ 按钮打开更多功能面板
2. 点击 🎫 卡券按钮
3. 在"我的卡券"标签选择一张可用卡券
4. 点击"下一步"
5. 输入转赠说明（可选）
6. 点击"确认转赠"

**预期结果**:
- 卡券消息显示在聊天窗口
- 卡券状态正确更新
- 显示转赠成功的 Toast 提示

**注意事项**:
- 目前为模拟数据
- 需要后端支持卡券转赠逻辑
- 需要数据库存储卡券记录

| 功能 | 技术要求 | 备注 |
|------|----------|------|
| 拍照 | MediaDevices API | 需要 HTTPS |
| 视频通话 | WebRTC | 需要信令服务器 |
| 位置共享 | Geolocation API | 需要 HTTPS |
| 文件上传 | File API | 全浏览器支持 |

## 已知问题

1. **视频通话**: 当前为模拟模式，需要实现完整的 WebRTC 信令服务器
2. **支付功能**: 红包、转账、礼物等支付功能为前端模拟
3. **文件上传**: 图片使用 Base64 编码，生产环境应使用文件上传服务
4. **地图集成**: 使用腾讯地图，需要申请 API Key
5. **性能优化**: 大量图片可能导致性能问题，需要实现虚拟滚动
