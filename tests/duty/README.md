# 智能值班表系统和一键呼叫功能 - 测试套件

## 概述

本测试套件为智慧乡村平台的**智能值班表系统**和**一键呼叫功能**提供全面的测试覆盖，确保系统的高质量和稳定性。

## 快速开始

### 运行所有测试
```bash
# Windows
run-duty-tests.bat

# Linux/Mac
./run-duty-tests.sh

# 或使用npm
npm test -- tests/duty
```


## 测试覆盖范围

### ✅ 已覆盖的功能

#### 1. 值班人员管理 (dutyPersonnel.test.js)
- 人员创建和验证
- 能力配置（班次类型、技能、资质、语言）
- 偏好设置（工作日偏好、连续天数限制、月度天数限制）
- `canHandleShift()` 方法 - 判断人员是否可承担某班次
- 二维码自动生成和验证
- 人员可用性判断
- 统计信息更新
- 村庄可用人员查询
- 健康状况记录
- 边界情况处理

#### 2. 值班表管理 (dutySchedule.test.js)
- 值班表创建和验证
- 值班记录管理（添加、更新、查询）
- **排班算法测试：**
  - 轮询算法（Round Robin）- 均衡分配
  - 平衡算法（Balanced）- 考虑偏好和负载
  - 优先级算法（Priority Based）
- 冲突检测（时间冲突、人员冲突）
- 连续天数限制验证
- 最小休息天数验证
- 置信度计算
- 任务和异常记录管理
- 考勤记录（签到、签退、位置、照片）
- 备勤人员管理
- 版本控制

#### 3. 紧急呼叫 (emergencyCall.test.js)
- 紧急呼叫发起和广播
- **Socket.IO实时通信：**
  - 房间管理（村庄隔离）
  - 事件处理（呼叫、接受、更新、完成）
  - 断线重连处理
- **位置服务：**
  - 准确位置记录（经纬度、精度、海拔）
  - 实时位置追踪
  - 位置历史记录
  - 距离计算（Haversine公式）
- **响应管理：**
  - 值班人员接受呼叫
  - 响应状态更新（前往中、到达中、处理中）
  - 多人同时响应
- **超时处理：**
  - 自动升级机制
  - 不同严重程度的超时设置
- 呼叫完成和结果记录
- 响应时间统计

#### 4. 调班功能 (dutyRotation.test.js)
- **调班申请：**
  - 创建调班申请（对调、替班）
  - 验证人员可用性
  - 日期合理性验证
  - 冲突检测
- **审批机制：**
  - 单级审批
  - 多级审批
  - 拒绝申请
  - 审批历史记录
- **交接班管理：**
  - 交接班信息记录
  - 双方确认机制
  - 异常情况记录
  - 附件上传
  - 值班状态转移
- **历史和统计：**
  - 调班历史查询
  - 调班频率统计
  - 频繁调班模式检测

#### 5. 完整流程 (dutyCompleteFlow.test.js)
- **8阶段完整流程：**
  1. 创建班次配置（早班、午班、晚班）
  2. 创建值班人员（5名不同职务和能力）
  3. 创建值班表
  4. 自动排班（使用平衡算法）
  5. 发布值班表
  6. 值班人员查看排班
  7. 紧急呼叫响应
  8. 完成呼叫并记录
- **调班完整流程：**
  1. 创建调班申请
  2. 管理员审批
  3. 更新值班记录
  4. 创建交接班记录
- **统计分析：**
  - 值班统计（天数、次数、时长）
  - 完成率计算
- **性能测试：**
  - 大规模排班（20班次 + 50人员）
  - 排班时间 < 10秒

## 测试特点

### 1. 全面的覆盖
- **单元测试：** 测试模型的各个方法和字段
- **集成测试：** 测试模块间的交互
- **端到端测试：** 测试完整的业务流程

### 2. 正常场景和边界情况
- ✅ 正常业务流程
- ✅ 数据验证（必填字段、格式、范围、唯一性）
- ✅ 边界值测试（最大长度、最小值、最大值）
- ✅ 异常情况处理（冲突、超时、断线）

### 3. Mock数据和隔离
- 使用 `mongodb-memory-server` 进行隔离测试
- Mock数据避免依赖外部服务
- 每个测试前自动清理数据库

### 4. 异步操作测试
- 所有异步操作使用 async/await
- Socket.IO 事件使用 Promise 包装
- 合理的超时设置（30秒用于E2E测试）

### 5. 详细的注释和文档
- 每个测试都有清晰的描述
- 测试步骤有详细的注释
- 使用 console.log 输出测试进度
